Core Web Standards

Explore the architectural components required to build standards-compliant web applications.

Structure

Semantic HTML5 Markup

HTML5 introduces native landmark elements that define document outline and role without reliance on generic div wrappers.

  • Document Landmarks: <header>, <nav>, <main>, <article>, <aside>, <footer>
  • Accessible Forms: Explicit label association via for/id attributes
  • Standards Compliance: Clean DOM hierarchy verified against W3C specification
HTML5 Landmark Skeleton
<header><nav>...</nav></header> <main> <article> <h1>Document Title</h1> </article> </main> <footer>© 2026 VSB-TUO</footer>
Styling

Modern CSS Layout Paradigms

CSS Flexbox and CSS Grid enable responsive, multidimensional layouts without external CSS frameworks like Bootstrap.

  • Box-Sizing: Standardized border-box model for predictable dimensional math
  • Flexbox: One-dimensional alignment for navigation bars and controls
  • CSS Grid: Two-dimensional structural grids with auto-fit minmax functions
  • CSS Custom Properties: Dynamic theme variables for clean runtime mode switches
CSS Reset & Grid
*, *::before, *::after { box-sizing: border-box; } .grid-layout { display: grid; grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); gap: 1.5rem; }
Interaction

Vanilla ECMAScript & DOM

Native JavaScript interacts directly with the Document Object Model (DOM) to manage user input, events, and dynamic state.

  • Event Listeners: Non-intrusive addEventListener() pattern
  • Client-Side Validation: Real-time input evaluation prior to submission
  • State Persistence: Browser localStorage for preferences and theme
  • Timers & Async: High-precision intervals for live clocks and countdowns
Native Event Handler
document.addEventListener("DOMContentLoaded", () => { const btn = document.querySelector("#submit-btn"); btn.addEventListener("click", (event) => { event.preventDefault(); validateForm(); }); });
Infrastructure

Client-Server Communication

The underlying communication pipeline connecting browser clients with web server infrastructures across the TCP/IP stack.

  • Request-Response Lifecycle: DNS lookup, TLS handshake, HTTP GET/POST
  • Status Codes: 2xx (Success), 3xx (Redirect), 4xx (Client Error), 5xx (Server Error)
  • Asset Optimization: Minimized payloads, SVG rendering, and cache headers
  • Hosting: Static deployment on Vercel, GitHub Pages, or VŠB Homel server
HTTP Headers Pattern
GET /index.html HTTP/1.1 Host: vsb.cz User-Agent: Mozilla/5.0 Accept: text/html,application/xhtml+xml Connection: keep-alive
