Technical Specifications

Core Architectural Pillars

Standard W3C • Pure Native Stack
Specification 01 HTML5 / DOM

Semantic HTML5 Structure

Semantic document architecture communicates structural intent, content hierarchy, and native accessibility parameters directly to user agents without presentation-driven wrappers.

  • Document Landmarks: <header>, <nav>, <main>, <article>, <aside>, <footer>
  • Accessible Forms: Strict programmatic labeling via paired for/id bindings
  • Validation: Syntactic compliance verified against the official W3C Living Standard
Document Outline Pattern
<header><nav>...</nav></header> <main> <article> <h1>Section Title</h1> </article> </main> <footer>© 2026 VSB-TUO</footer>
Specification 02 CSS3 / LAYOUT

Modern CSS Layout Paradigms

CSS Grid and Flexbox supply multi-axis positioning and predictable dimension computation across all physical viewport widths without third-party frameworks.

  • Box-Sizing: Border-box declaration for deterministic padding and border mathematics
  • Flexbox: One-dimensional linear distribution for navigation bars and controls
  • CSS Grid: Two-dimensional structural layouts utilizing repeat(auto-fit, minmax(...))
  • CSS Variables: Centralized design tokens for sharp editorial consistency
Box Model & Grid Rules
*, *::before, *::after { box-sizing: border-box; } .editorial-grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(320px, 1fr)); gap: 24px; }
Specification 03 ECMASCRIPT / DOM

Native ECMAScript & DOM

Direct manipulation of the Document Object Model using modern ES6+ paradigms to orchestrate user interactions, state transitions, and form validation routines.

  • Event Handling: Non-intrusive addEventListener() patterns
  • Client Validation: Immediate constraint verification prior to HTTP dispatch
  • Persistent State: Client-side storage via browser localStorage
  • Precision Timers: High-resolution setInterval cycles for live clocks and counters
Event Registration
document.addEventListener("DOMContentLoaded", () => { const trigger = document.querySelector("#submit-btn"); trigger.addEventListener("click", (event) => { event.preventDefault(); verifyFormIntegrity(); }); });
Specification 04 NETWORKING / HTTP

Client-Server Pipeline

The networking foundation connecting the browser runtime to host infrastructures across DNS resolution, TLS handshakes, and stateless HTTP request-response cycles.

  • Lifecycle: DNS query, TCP three-way handshake, TLS negotiation, HTTP GET
  • Status Protocol: 2xx (Success), 3xx (Redirect), 4xx (Client Error), 5xx (Server Error)
  • Performance: Lightweight asset footprints and geometric SVG rendering
  • Deployment: Continuous delivery via GitHub Pages and Vercel hosting
HTTP Request Envelope
GET /index.html HTTP/1.1 Host: vsb.cz User-Agent: Mozilla/5.0 Accept: text/html,application/xhtml+xml Connection: keep-alive
